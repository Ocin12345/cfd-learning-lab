## Execution precautions

Use fresh versioned outputs and preserve the original cases. On the original workstation, dot-source code/Use-Project.ps1 and use E:/CFD-Learning-Lab/environments/fluent/Scripts/python.exe. Include this lesson's code directory and the repository scripts directory in PYTHONPATH. The scripts preserve their executed local paths, so a fresh rerun must adapt explicit output paths/whitelists in a new copy; do not target the preserved originals. Check disk/RAM and actual licence admission. Use two ranks/processes, one hidden solver at a time.

Run the flat and tilted qualifications before production. The selected tilted Fluent driver is sloshing_fluent_qualification_v007.py with audit_sloshing_fluent_v005.py; the selected raw flat driver/auditor are v005/v003. The v001 Fluent qualification file is a historical helper dependency of the auditors; its original driver is not an accepted setup. Set CFD_SLOSHING_TILT to 0 for flat and 0.025 for tilted cases. prepare_sloshing_openfoam_v001.py builds the corresponding small case. Qualification admission verifies all four actual audit files and the native source hashes they reference.

The completed production used sloshing_fluent_production_v001.py, preserved exactly. For future unattended reruns use sloshing_fluent_production_v002.py: it refreshes qualification/native-source hashes after the RAM wait and mesh preparation, immediately before Fluent launch. check_stale_qualification_admission_v002.py is a dry-run regression using copies of actual audit files and one copied native input; it never starts Fluent. Pass the chosen driver path as its argument. The original v001 behavior fails this test and v002 passes. Its admission helper requires the successful local qualification archives. The selected OpenFOAM inputs are the supplied openfoam-inputs directory, with alpha tolerance 1e-11 and p_rgh tolerance 1e-10. run_sloshing_openfoam_production_v003.sh executes mesh checks, two-rank solving and reconstruction. Its fixed path whitelist must be adapted in a new script copy for a new output directory.

The final numerical auditors are audit_sloshing_fluent_production_v001.py and audit_sloshing_openfoam_production_v003.py. The renderer is render_paired_sloshing_v003.py, which requires --openfoam-case, --openfoam-audit and a fresh --out directory; it refuses failed full audits and binds every selected native field to its corresponding source hash. The video/GIF exporters decode all 121 frames and check the rendered data; the FFmpeg installation is separate from the repository. The original E: installation receipt is tools/video-export-v001/installation-receipt.json.

For an exact rerun on a new machine, first recreate or obtain the separate qualification archives and update the guarded paths consistently; the repository alone is not a one-command native restart. Never delete an existing project to make a script accept a path.
