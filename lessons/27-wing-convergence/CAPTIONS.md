# Actual native finite-wing visualization

Full-span rectangular wing, chord 1 m, span 4 m, nominal AR=4, clockwise 8 degree pitch about the span axis; NACA0012-like closed rounded-tail profile, not an exact NACA0012 claim. Declared steady incompressible laminar conditions are U=(1,0,0) m/s, rho=1 kg/m3 and mu=0.0025 Pa.s, nominal Re_c=400. Native setup, residual, mass and force-stability evidence is assessed separately; rendered appearance does not establish convergence.

Every native tetrahedron is reconstructed from saved face/owner/neighbour IDs and matched bijectively to the common source geometry; imported ordering is never assumed. Saved velocity and pressure are finite. For traces, actual cell vectors are volume-weighted to incident original vertices and interpolated linearly inside original fluid tetrahedra. RK4 substage and final-point segments walk adjacent tetrahedra; crossing a fluid boundary stops integration. No streamline is permitted to jump through the wing. No analytic vortex or imposed boundary sample enters reconstruction. These are sparse-mesh interpolation/gradient approximations.

When generated, the GIF depicts fixed computed steady fields: particle phase progression and a quiet common camera orbit provide motion. This is steady-field visualization, not simulated transient vortex development. Recycled tracers use fixed offsets along their own actual integrated paths; integration travel time and GIF playback time are separate from any solver iteration counter. Actual weak or absent tip roll-up is retained. Both codes in any paired view share speed limits, camera, axes in metres, and visible-domain crop. Physical y is displayed vertically using the labelled plotting-coordinate permutation (x,z,y). Generated RK4 paths/time samples are exported.

Surface Cp=(p-0)/(rho*U^2/2) uses saved wing-face/boundary values when available. Each panel labels an owner-cell pressure proxy if native face values were unavailable; proxy pressure is not exact wall pressure. The downstream y-z section is made by intersecting actual fluid tetrahedra, splitting only actual intersection quadrilaterals into triangles. Signed streamwise vorticity is dw/dy-dv/dz of the linear reconstructed field. Sparse arrows show actual interpolated crossflow at native intersection centroids, with one shared arrow scale/key. Any user-requested vorticity colour saturation is explicit in the colorbar and checks.

Native source hashes, executed source, interpolation/trace diagnostics, actual surface pressures and slice arrays accompany these figures. No aircraft-performance, benchmark-accuracy, mesh/time independence or physical-validation claim is made. Fluent and OpenFOAM computed the fields; Codex prepared this workflow.
