# Actual transient cylinder fields

Paired native Fluent/OpenFOAM snapshots span 2.05 to 4 s at 40 matching physical times. Time interpolation is never used. The channel is 2.2 by 0.41 m, with a cylinder centred at (0.2,0.2) m of diameter 0.1 m. Declared conditions are rho=1 kg/m3, mu=0.001 Pa.s, parabolic inlet of mean 1 m/s and peak 1.5 m/s, and Re_D=100. These declarations must be checked against separate native run receipts.

The requested start time is 2.05 s. Only actual matched snapshots in the displayed window 2.05..4 s are loaded, rendered and exported here; force histories are filtered to the same requested lower bound and matched end time. Full native source histories retain the original 0..2 s startup pilot, which was under-converged relative to the declared residual targets. Later continuations change nonlinear iteration controls while retaining the 0.005 s time step; those settings changes alone do not establish that the later window passes numerical checks. The complete source timeline is not relabelled as a corrected calculation.

Speed is the actual saved cell-centred hypot(u,v), shown flat on each native fluid triangle. Triangles are reconstructed from saved face/owner/neighbour IDs independently in each code; their projected geometric correspondence is verified. Native cell order is never assumed. Gray masks the polygonal cylinder with an analytic circle; no artificial flow is drawn there. The x and y axes use metres and equal geometric scale. Every speed frame and both codes use one linear color range [0, 2.22850555] m/s, containing all paired native values. No streamlines or synthetic vortex motion are added.

Signed vorticity is an explicitly postprocessed numerical reconstruction: area-weighted cell-centred u and v are averaged to their own incident native mesh vertices, then curl dv/dx-du/dy is calculated from the linear field within each saved fluid triangle. No Delaunay mesh, cross-cylinder triangle, analytic vortex, imposed wall sample or synthetic gradient enters this calculation. Boundary derivatives have reconstruction error and are not native solver gradient exports. A single symmetric linear display range [-60, 60] per second is shared by both codes and every selected paired time. Colours saturate outside ±60 s^-1; the colorbar shows extension triangles at both ends. Only display colours saturate: actual native-cell reconstructions and CSV values are unchanged. Full extrema, below/above-range counts and saturated cell fractions for each code and physical time are in checks.json.

Requested playback is 20 frames/s; GIF uses the nearest 10 ms frame delay, recorded in checks.json. Physical time is printed on every frame; playback speed is separate from physical simulation speed. The exact rendered physical times, any unpaired snapshots, native field ranges, matching-cell differences, and native source hashes are recorded in the accompanying checks and CSVs. Compressed CSVs contain the actual per-cell fields for every paired time; OpenFOAM kinematic p is expressed as Pa using rho=1 kg/m3. Forces are plotted only if actual source force CSVs were supplied.

A transient picture is not evidence of a statistically stationary or periodic shedding state, a validated Strouhal number, mesh independence or physical validation. Fluent and OpenFOAM calculated the fields.
